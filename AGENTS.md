
## Ícones obrigatórios

Em todo o site, use o SVG existente `static/img/icons/check.svg` para confirmação e seleção. Use `static/img/icons/x.svg` para fechar, cancelar ou remover quando houver um ícone X. Nunca substitua esses ícones por caracteres Unicode, emojis, desenhos CSS ou outros SVGs. Reutilize os arquivos via máscara CSS para respeitar a cor do tema. Mantenha os rótulos acessíveis dos botões.
