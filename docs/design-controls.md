# Controles de interface

Referência: Apps in ChatGPT · OpenAI Official (Community), pranchas Checkbox, Radio, Toggle e Segmented Control enviadas pelo usuário.

- Checkbox: contorno neutro quando vazio; preenchimento na cor primária do texto quando selecionado, com check.svg contrastante. Estado parcial usa selected-partial.svg.
- Radio: círculo de contorno neutro; selecionado com anel espesso na cor primária e centro contrastante. Aplicar quando existir um grupo de opções de rádio; não substituir os checks dos menus.
- Toggle: trilho cinza desligado, azul ligado e botão circular branco em ambos os temas. Hover desligado reforça o cinza; desabilitado reduz opacidade; foco de teclado visível.
- Controle segmentado: fundo neutro compartilhado e opção ativa contrastante; variante arredondada para a cápsula e retangular arredondada para o tipo de gráfico. Manter 2 px de margem interna e nenhuma sombra na cápsula, conforme pedido anterior.
- Cores dos estados seguem as variáveis do tema. Abas de navegação permanecem abas, sem conversão em controles segmentados.
- As pranchas são referências visuais sem medidas CSS declaradas; dimensões foram adaptadas aos controles existentes.
